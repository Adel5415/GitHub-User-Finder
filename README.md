# GitHub User Finder

**Автор:** Адель Музафаров

## Описание

`GitHub User Finder` — это GUI-приложение на Python для поиска пользователей GitHub через GitHub API. Программа позволяет искать аккаунты GitHub, отображать найденных пользователей в списке, открывать профиль в браузере, добавлять пользователей в избранное и сохранять избранное в JSON-файл.

### Возможности программы

- поиск пользователей GitHub по логину;
- отображение результатов поиска в виде списка;
- открытие профиля пользователя в браузере;
- добавление пользователей в избранное;
- удаление пользователей из избранного;
- сохранение избранных пользователей в файле `favorites.json`;
- проверка корректности ввода;
- очистка поля поиска и списка избранного.

## Используемое API

В проекте используется **GitHub API**.

### Получение информации о пользователе

Если введён точный логин, приложение обращается к следующему адресу:

`https://api.github.com/users/{login}`

### Поиск пользователей

Если точный пользователь не найден, выполняется поиск по GitHub API:

`https://api.github.com/search/users?q={query}&per_page=20`

## Как использовать API

GitHub API позволяет получать данные о пользователях по HTTP-запросам и возвращает ответ в формате JSON.  
Программа использует следующие данные из ответа:

- `login` — логин пользователя;
- `html_url` — ссылка на профиль;
- `avatar_url` — ссылка на аватар;
- `score` — показатель совпадения при поиске.

### Заголовки запроса

Приложение отправляет такие заголовки:

- `Accept: application/vnd.github+json`
- `User-Agent: GitHubUserFinderApp`

Если у вас есть GitHub token, его можно добавить через переменную окружения `GITHUB_TOKEN`.  
Тогда программа будет использовать авторизацию при обращении к API.

## Как пользоваться программой
1.Введите логин пользователя GitHub в поле поиска.
2.Нажмите кнопку Поиск.
3.Дождитесь появления результатов.
4.Выберите пользователя из списка.
5.Нажмите:
    1.Открыть профиль — чтобы открыть страницу пользователя в браузере;
    2.В избранное — чтобы добавить пользователя в избранное.
6.В разделе Избранное можно:
    1.открыть профиль выбранного пользователя;
    2.удалить пользователя из списка;
    3.очистить всё избранное.
  Избранные пользователи автоматически сохраняются в файл favorites.json.

## Проверка корректности ввода
Если поле поиска пустое, программа не выполняет запрос и показывает предупреждение.

### Примеры использования
Пример 1: Поиск пользователя
Ввод: octocat

Результат: программа выводит найденного пользователя GitHub в список результатов.

Пример 2: Добавление в избранное
Шаги:

1.Ввести логин пользователя.
2.Нажать Поиск.
3.Выбрать пользователя из списка.
4.Нажать В избранное.
Результат: пользователь добавляется в список избранного и сохраняется в favorites.json.

Пример 3: Пустой поиск
Шаг: нажать Поиск без ввода текста.

Результат: появляется сообщение о том, что поле поиска не должно быть пустым.

Пример 4: Удаление из избранного
Шаги:

Выбрать пользователя в списке избранного.
Нажать Удалить.
Результат: пользователь удаляется из списка и из файла favorites.json.
